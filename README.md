# Raseo

> **An open-source Agent SDK for JavaScript and TypeScript.**

Build AI agents with a unified API across leading LLM providers.

**Build once. Choose any model.**

### Supported Providers

* OpenAI
* Google Gemini
* Anthropic Claude
* Ollama (Local Models)

Raseo provides a consistent developer experience for building AI applications without locking you into a single model provider.
